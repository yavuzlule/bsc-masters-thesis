Variables locales y globales Como cualquier otro DOS, Amiga se ocupa de las variables de entorno que se utilizan en la programación por lotes. Hay variables globales y locales, y se hace referencia a ellas con un signo de dólar delante del nombre de la variable, por ejemplo $myvar. Las variables globales están disponibles en todo el sistema; Las variables locales solo son válidas en el shell actual. En caso de colisión de nombres, las variables locales tienen prioridad sobre las variables globales. Las variables globales se pueden configurar con el comando SetEnv, mientras que las variables locales se pueden configurar con el comando Set. También hay los comandos GetEnv y Get que se pueden usar para imprimir variables globales y locales respectivamente. Los siguientes ejemplos demuestran un uso simple: setenv foo blapp echo $foo blapp set foo bar echo $foo bar getenv foo blapp get foo bar type ENV:foo blapp setenv save foo $foo type ENV:foo bar type ENVARC:foo bar Observe el indicador de guardado del comando SetEnv y cómo las variables globales están disponibles en el sistema de archivos. Las variables globales se guardan como archivos en ENV: y, opcionalmente, se guardan en el disco en ENVARC: para sobrevivir al reinicio y al ciclo de energía.
